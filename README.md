# 📊 Super Store Sales Dashboard (Power BI)

## 📌 Project Overview

This project showcases an interactive **Sales Dashboard** built using **Power BI** to analyze and visualize sales performance across regions, categories, and time periods.

It enables users to monitor KPIs, identify trends, and make data-driven decisions effectively.

---

## 🎯 Objectives

* Analyze monthly and yearly sales trends
* Compare profit performance (Year-over-Year)
* Identify top-performing categories and sub-categories
* Understand regional sales distribution
* Deliver an interactive business intelligence solution

---

## 📈 Dashboard Features

* 📅 **Sales Trend Analysis** (Monthly & Yearly comparison)
* 💰 **Profit Analysis** with YoY insights
* 📦 **Category & Sub-Category Breakdown**
* 🧑‍💼 **Segment Analysis** (Consumer, Corporate, Home Office)
* 🗺️ **Geographical Analysis** (Sales by State)
* 🎛️ Interactive filters and slicers

---

## 🛠️ Tools & Technologies

* **Power BI**
* Data Cleaning & Transformation
* Data Visualization

---

## 📂 Dataset

* Super Store Sales Dataset (Sample Dataset)
* Contains order details, sales, profit, region, and category information

---

## 🚀 Insights

* 📊 Technology and Office Supplies drive major revenue
* 📈 Sales peak during the end of the year
* 🌍 Certain regions consistently outperform others
* ⚠️ Profit does not always increase with sales
